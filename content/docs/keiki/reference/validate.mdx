`validateTransducer` is keiki's build-time validation umbrella. You drop
`validateTransducer defaultValidationOptions t == []` straight into a unit test and it passes or
fails in **microseconds with no external z3 process** — it walks the `HsPred` carrier
syntactically. For the design rationale see [Why SMT](/docs/keiki/explanation/why-smt) and
[The symbolic CI gate](/docs/keiki/explanation).

<Callout type="warn">
keiki's transducer validator `validateTransducer` lives in **`Keiki.Core`** (re-exported from
[`Keiki.Symbolic`](/docs/keiki/reference/symbolic)). It is unrelated to `Keiki.Render.Validate`,
which is a Mermaid-diagram and atlas **text** checker exporting `validateMermaidDiagram` and
`validateMermaidAtlas` (documented under rendering, operating on rendered `Text`, sharing no
code). Do not confuse the two — they only resemble each other in the pure list-of-warnings house
style.
</Callout>

## `validateTransducer`

```haskell
validateTransducer ::
    (Bounded s, Enum s, Ord s, Show s) =>
    ValidationOptions ->
    SymTransducer (HsPred rs ci) rs s ci co ->
    [TransducerValidationWarning s]
```

It runs the enabled checks over the `HsPred` carrier and concatenates their structured warnings,
in order: hidden inputs, head recoverability, inversion ambiguity, guarded input reads,
state-changing ε-output, determinism, dead edges, and the opt-in opaque-guard audit. The default path
is deliberately specialised to `HsPred` and is **cheap and pure**.

<Callout type="warn">
**Gotcha — the pure path is under-approximating, the polymorphic path over-approximates.**
`validateTransducer` calls `checkTransitionDeterminismPure`, which emits a warning only when
overlap is *structurally provable* (no false positives, but it can miss overlaps it cannot prove
syntactically). The separate `BoolAlg`-polymorphic `checkTransitionDeterminism` over-approximates
on the raw `HsPred` carrier (its `isBot` only recognises literal `PBot`, so it would flag almost
every multi-edge vertex) and is only meaningful through
[`checkTransitionDeterminismSym`](/docs/keiki/reference/symbolic), which routes `isBot` to z3. So:
`validateTransducer` for a fast pure no-false-positive gate; `checkTransitionDeterminismSym` /
`checkDeadEdgesSym` (need z3 on `PATH`) for the stronger supported-fragment analysis. It treats
solver uncertainty conservatively rather than claiming a proof.
</Callout>

## `ValidationOptions` and `defaultValidationOptions`

Construct options by record-updating `defaultValidationOptions`, so future fields retain their safe
defaults. Every replay-safety and structural check is on; the advisory opaque-guard audit is opt-in.

## `TransducerValidationWarning`

A structured warning parameterized over the vertex type `s`, so it carries the real source vertex.
It reuses the canonical [`EdgeRef`](/docs/keiki/reference/step-failure) locator owned by the
runtime explainer `stepEither`, so build-time and runtime diagnostics speak one vocabulary.

```haskell
data TransducerValidationWarning s
    = HiddenInput
        { tvwEdge         :: EdgeRef s
        , tvwInCtor       :: Maybe String   -- input constructor name, when known
        , tvwMissingSlots :: [String]       -- slot/field names left off the wire
        , tvwDetail       :: String         -- human-readable summary
        }
    | HeadUnrecoverable
        { tvwEdge          :: EdgeRef s
        , tvwInCtor        :: Maybe String
        , tvwTailOnlySlots :: [String]
        , tvwDetail        :: String
        }
    | InversionAmbiguity
        { tvwSource   :: s
        , tvwEdgeA    :: Int
        , tvwEdgeB    :: Int
        , tvwWireCtor :: String
        , tvwDetail   :: String
        }
    | UnguardedInputRead
        { tvwEdge   :: EdgeRef s
        , tvwInCtor :: Maybe String
        , tvwDetail :: String
        }
    | StateChangingEpsilon
        { tvwEdge            :: EdgeRef s
        , tvwChangesVertex   :: Bool
        , tvwWritesRegisters :: Bool
        , tvwDetail          :: String
        }
    | NondeterministicPair
        { tvwSource :: s
        , tvwEdgeA  :: Int
        , tvwEdgeB  :: Int
        , tvwInCtor :: Maybe String
        , tvwDetail :: String
        }
    | PossiblyDeadEdge
        { tvwEdge   :: EdgeRef s
        , tvwDetail :: String
        }
    | OpaqueGuard
        { tvwEdge   :: EdgeRef s
        , tvwDetail :: String
        }
    | ProjectionResultUnsupported
        { tvwEdge                 :: EdgeRef s
        , tvwProjectionPath       :: String
        , tvwProjectionShape      :: String
        , tvwProjectionResultType :: String
        , tvwDetail               :: String
        }
    | ProjectionOrderingUnsupported
        { tvwEdge                 :: EdgeRef s
        , tvwProjectionPath       :: String
        , tvwProjectionShape      :: String
        , tvwProjectionResultType :: String
        , tvwDetail               :: String
        }
    | ProjectionOutsideGuard
        { tvwEdge                :: EdgeRef s
        , tvwProjectionPath      :: String
        , tvwProjectionShape     :: String
        , tvwProjectionLocation  :: String
        , tvwDetail              :: String
        }
    deriving stock (Eq, Show)
```

<Callout type="warn">
  **Breaking in keiki 0.4.0.0.** `TransducerValidationWarning` gained the three `Projection*`
  constructors. Code that matches it exhaustively must handle them.
</Callout>

- **`HiddenInput`** — an edge consumes command information its output does not emit, so the command
  cannot be reconstructed on replay (the un-replayable-event mistake; the UserRegistrationV0 foil).
- **`HeadUnrecoverable`** — later events carry command fields missing from the first event. Streaming
  replay inverts only the head, so the produced chain cannot be replayed.
- **`InversionAmbiguity`** — two outgoing edges use the same head wire constructor and may both
  explain one observed event. It is conservative because this pure structural pass cannot prove
  recovered-value guard disjointness in general.

  <Callout type="warn">
    **Changed in keiki 0.9.0.0 — expect a different warning set after recompiling.** "Same head wire
    constructor" is now decided by **structural head classification**, not by name equality. And the
    check suppresses a same-mode warning when exact integral register-versus-literal conjuncts prove
    the two candidates disjoint, so some warnings that used to fire no longer do.

    Unsupported and opaque guards remain conservative warnings, and their `tvwDetail` now identifies
    the construct that blocked the cheap proof. Runtime replay is unchanged. For a solver-backed
    escalation see
    [`checkInversionAmbiguitySym`](/docs/keiki/reference/symbolic#replay-inversion-ambiguity-analysis),
    which is opt-in and removes a warning only on a definite UNSAT.
  </Callout>
  **Keiki 0.9.1.0** also proves complementary standard `Bool` register guards
  disjoint by evaluating their captured equality/ordering closures at both `False` and `True`.
  Integral interval reasoning is unchanged. The proof descends through `PAnd`, but does not
  enter `POr` or `PNot`; arbitrary consumer `Bounded`/`Enum` instances, unregistered equality
  anchors, and opaque guards supply no proof. Unsupported sibling conjuncts may be dropped as
  weakening when the supported conjuncts already prove a contradiction. Public validation
  signatures and runtime replay are unchanged.

- **`UnguardedInputRead`** — a guard, update, or output reads an input constructor field without an
  earlier matching top-level `PInCtor` conjunct. Another command could reach the read and throw.
- **`StateChangingEpsilon`** — an output-free edge changes vertex, can write registers, or both, so
  persisting only emitted events loses the forward transition.
- **`NondeterministicPair`** — two outgoing edges of one vertex whose guards can both hold for one
  command: a single-valuedness violation whose *dynamic* witness is
  [`AmbiguousEdges`](/docs/keiki/reference/step-failure).
- **`PossiblyDeadEdge`** — an edge that can never fire: its source vertex is unreachable from
  `initial`, or its guard is statically unsatisfiable. Labelled "possibly" because the structural
  pass is conservative.
- **`OpaqueGuard`** — an edge whose guard branches on a term the symbolic analyses translate to an
  unconstrained free variable, so they silently under-verify it. Advisory, not a soundness error;
  opt in via `warnOpaqueGuards`.

  <Callout type="warn">
    **Widened in keiki 0.5.0.0.** The audit used to cover only opaque `TApp` terms. It now also
    reports a **`TArith` whose carrier is absent from the symbolic numeric registry** — structural
    arithmetic the solver still cannot read. Consequently `tvwDetail` no longer names `TApp`
    specifically, so a test asserting on the exact message text needs updating. (`Natural` was the
    motivating case in 0.5.0.0 and was itself admitted to the numeric registry in 0.6.0.0, so it no
    longer triggers the warning.)
  </Callout>
- **`ProjectionResultUnsupported`** — a [field
  projection](/docs/keiki/reference/core#field-projections)'s result type is outside the curated
  symbolic **equality** registry. Translating such a guard would fall back to an opaque Boolean and
  silently lose the promised proof.
- **`ProjectionOrderingUnsupported`** — a projection occurs under an **ordering** comparison but its
  result type has no curated symbolic ordering dictionary.
- **`ProjectionOutsideGuard`** — a projection occurs in an update or an output. Projections are a
  guard-only structural feature; raw evaluation stays total, but default validation rejects this
  placement. `tvwProjectionLocation` says where it was found.

<Callout type="info">
  The three projection findings are **unconditional** — they are not gated by a `ValidationOptions`
  flag. Each carries the projection's diagnostic `tvwProjectionPath`
  (`fieldProjectionPath`) and `tvwProjectionShape` (`fieldShapeId`) so a generator can point at the
  offending binding.
</Callout>

## Edge mode and the static checks

*(keiki 0.3.0.0.)* Introducing [`ReplayOnly`](/docs/keiki/reference/core#edge-mode) edges made two
checks mode-aware and deliberately left the rest alone:

| Check family | Scope |
|---|---|
| Determinism (`checkTransitionDeterminism`, `checkTransitionDeterminismPure`, `determinismWarnings`, `isSingleValuedSym`) | **`Live`/`Live` pairs only** — only live edges compete in forward dispatch |
| `inversionAmbiguityWarnings` | **same-mode pairs only** — cross-mode pairs are resolved deterministically by the live-first inversion phase order |
| Hidden-input, head-recoverability, guard-implies-input-read, state-changing epsilon, opaque-guard, both dead-edge analyses | applied to replay-only edges **unchanged** |

<Callout type="info">
  Structural reachability still **traverses replay-only targets**: a vertex reachable only through a
  replay-only edge stays live for the purposes of replay continuation, so it is not reported as a
  `PossiblyDeadEdge` source.
</Callout>

## The per-component checks

The replay checks are also exported individually for focused tests:

```haskell
hiddenInputWarnings ::
    (Bounded s, Enum s) =>
    SymTransducer phi rs s ci co ->
    [TransducerValidationWarning s]

headRecoverabilityWarnings ::
    (Bounded s, Enum s) =>
    SymTransducer phi rs s ci co ->
    [TransducerValidationWarning s]

inversionAmbiguityWarnings ::
    (Bounded s, Enum s, Show s) =>
    SymTransducer (HsPred rs ci) rs s ci co ->
    [TransducerValidationWarning s]

guardImpliesInputReadWarnings ::
    (Bounded s, Enum s, Show s) =>
    SymTransducer (HsPred rs ci) rs s ci co ->
    [TransducerValidationWarning s]

stateChangingEpsilonWarnings ::
    (Bounded s, Enum s, Eq s, Show s) =>
    SymTransducer (HsPred rs ci) rs s ci co ->
    [TransducerValidationWarning s]

opaqueGuardWarnings ::
    (Bounded s, Enum s) =>
    SymTransducer (HsPred rs ci) rs s ci co ->
    [TransducerValidationWarning s]
```

`hiddenInputWarnings` covers fields omitted from the whole output chain; `headRecoverabilityWarnings`
covers fields present only after its head. The guard-read check walks the top-level `PAnd` spine from
left to right, matching lazy `(&&)`: a constructor guard to the right of a field read is too late.
`stateChangingEpsilonWarnings` is exact for vertex changes and conservative for register writes.
`opaqueGuardWarnings` is the opt-in audit; `TArith` is transparent, while `TApp1`/`TApp2` count as
opaque.

### Determinism

The determinism component is driven by the **pure** `provablyOverlap`, which is `True` only when a
concrete overlap is structurally proved:

```haskell
provablyOverlap :: HsPred rs ci -> HsPred rs ci -> Bool
provablyOverlap PLeftArm PLeftArm = True
provablyOverlap PRightArm PRightArm = True
provablyOverlap a b = case (pureFragment a, pureFragment b) of
  (PureKnown left, PureKnown right) -> pureGuardsOverlap left right
  _ -> False
```

The accepted fragment walks top-level conjunctions containing constructor tests and
variable-versus-literal comparisons. Integral bounds use exact interval reasoning — including
`Natural`, modelled as the exact interval `[0, ∞)` since keiki 0.5.0.0, so the validator can find
non-literal interior witnesses for it. Other supported
types use concrete literal witnesses. Disjunction, negation, arithmetic, opaque applications,
variable-versus-variable comparison, and non-integral strict-bound density remain unknown and
produce no pure warning. `NondeterministicPair` therefore has **no false positives**, but silence
outside the fragment is not proof of determinism. The reusable forms are:

```haskell
data DeterminismWarning s = DeterminismWarning
    { dwSource :: s
    , dwEdgeA  :: Int   -- first overlapping edge index
    , dwEdgeB  :: Int   -- second overlapping edge index
    , dwDetail :: String
    }
    deriving stock (Eq, Show)

checkTransitionDeterminism ::
    forall phi rs s ci co.
    (BoolAlg phi (RegFile rs, ci), Bounded s, Enum s, Show s) =>
    SymTransducer phi rs s ci co ->
    [DeterminismWarning s]
```

`checkTransitionDeterminism t == []` iff `isSingleValuedSym t` **under the same carrier** — which
is why it is meant for the `SymPred` carrier (run it via
[`checkTransitionDeterminismSym`](/docs/keiki/reference/symbolic)), not the raw `HsPred` carrier
where it over-approximates.

### Dead edges (reachability)

```haskell
data DeadEdgeOptions = DeadEdgeOptions
    { deoFlagBotGuards :: Bool
    }
    deriving stock (Eq, Show)

defaultDeadEdgeOptions :: DeadEdgeOptions   -- deoFlagBotGuards = True

data DeadEdgeWarning s = DeadEdgeWarning
    { dewEdge   :: EdgeRef s
    , dewReason :: String
    }
    deriving stock (Eq, Show)

checkDeadEdges ::
    (Bounded s, Enum s, Ord s, Show s) =>
    DeadEdgeOptions ->
    SymTransducer (HsPred rs ci) rs s ci co ->
    [DeadEdgeWarning s]
```

`checkDeadEdges` is **purely structural**: it flags an edge whose source vertex is unreachable from
`initial` (computed by a `reachableVertices` finite fixpoint over the `Bounded`/`Enum` vertex set,
following `target` pointers) or, when `deoFlagBotGuards` is on, whose guard is the literal `PBot`.
It **cannot reason about register values** — a self-loop guarded `available == True` whose
`available` is set `False` on entry is not catchable here — which is why every result is labelled
"possibly dead", and the register-aware escalation is
[`checkDeadEdgesSym`](/docs/keiki/reference/symbolic).
