Reservation work is a Hospital-local typed Keiro PGMQ job. Kafka carries public cross-service
contracts; this queue supplies visibility leases, retry, and a real DLQ for local work.

## Generated policy, hand-owned payload

From `mori://shinzui/keiro-runtime-jitsurei`, project-relative path `services/hospital-capacity/src/HospitalCapacity/Reservation/WorkQueue.hs`
(artifact-level URI pending):

```haskell
reservationWorkJob :: Job ReservationWorkItem
reservationWorkJob =
  Job
    { jobName = "reservation-work"
    , jobQueue = queueRef GeneratedQueue.queuePhysical
    , jobCodec = reservationWorkJobCodec
    , jobPolicy = validatedReservationWorkRetryPolicy
    }

validatedReservationWorkRetryPolicy :: RetryPolicy
validatedReservationWorkRetryPolicy =
  case
    mkRetryPolicy
      GeneratedPolicy.retryPolicy.maxRetries
      GeneratedPolicy.retryPolicy.defaultRetryDelay
      GeneratedPolicy.retryPolicy.useDeadLetter of
    Right policy -> policy
    Left err -> error ("invalid generated reservation-work retry policy: " <> show err)
```

The generated queue name and policy configure `Job ReservationWorkItem`; the hand codec validates
its message body. `reservation-work setup` reconciles the work and DLQ queues after the base PGMQ
migration component has been applied.

## One-shot processing

From `mori://shinzui/keiro-runtime-jitsurei`, project-relative path `services/hospital-capacity/src/HospitalCapacity/Reservation/WorkQueue.hs`
(artifact-level URI pending):

```haskell
runReservationWorkConsumerOnceWithTelemetry :: Maybe Tracer -> HospitalCapacityStore -> Pool.Pool -> IO (Either PgmqRuntimeError Int)
runReservationWorkConsumerOnceWithTelemetry tracer store pool =
  runPgmqIOWithTelemetry tracer pool $ do
    ensureJobQueueWith GeneratedPolicy.queueProvision reservationWorkJob
    runJobOnceWithContext
      (GeneratedPolicy.jobTuningFor defaultJobTuning)
      1
      reservationWorkJob
      (\_context -> handleReservationWork tracer store)

handleReservationWork :: (IOE :> es) => Maybe Tracer -> HospitalCapacityStore -> ReservationWorkItem -> Eff es JobOutcome
handleReservationWork tracer store item = do
  result <- liftIO (dispatchReservationWork tracer store item)
  pure $
    case result of
      Left failure -> reservationWorkFailureOutcome failure
      Right () -> Done

reservationWorkFailureOutcome :: ReservationWorkFailure -> JobOutcome
reservationWorkFailureOutcome = \case
  ReservationWorkDecodeFailed err ->
    withDeadReason err (GeneratedPolicy.jobOutcomeFor "decodeFailure")
  ReservationWorkStoreFailed _err ->
    GeneratedPolicy.jobOutcomeFor "storeFailure"
  ReservationWorkCommandRejected err ->
    withDeadReason err (GeneratedPolicy.jobOutcomeFor "commandRejected")
```

This application uses `runJobOnceWithContext`, not the continuous Shibuya job processor. It reads
and finalizes directly at the pinned runtime version. Generated policy maps decode, store, and
command-rejection failures to job outcomes; retryable store failure and terminal bad work remain
distinct. Malformed or exhausted messages go to `hospital_capacity_reservation_work_dlq`.

## Redelivery boundary

`dispatchReservationWork` first checks whether this reservation/source-message pair already
applied, then runs the validated reservation command. Stable event IDs and the service's replay
tests provide evidence that redelivery produces one reservation event.

From `mori://shinzui/keiro-runtime-jitsurei`, project-relative path `services/hospital-capacity/src/HospitalCapacity/Reservation/WorkQueue.hs`
(artifact-level URI pending):

```haskell
reservationWorkAlreadyApplied :: HospitalCapacityStore -> ReservationWorkItem -> IO (Either StoreError Bool)
reservationWorkAlreadyApplied store item =
  runHospitalCapacityStore store $
    runTransaction $
      Tx.statement (item.reservationId, item.sourceMessageId) selectReservationWorkAppliedStmt
```

The one-shot path emits PGMQ publish/receive and domain-command evidence, but does not establish
remote-parent extraction or a Shibuya job process span at this app's pinned dependency revision.
