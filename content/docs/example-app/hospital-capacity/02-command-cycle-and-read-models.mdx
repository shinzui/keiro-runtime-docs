Hospital Capacity uses the same validated command boundary as Incident Command, with its own
process-level `HospitalCapacityStore`. A typed command ID supplies deterministic event IDs, and
the requested inline projections participate in the append transaction.

## The command boundary

From `mori://shinzui/keiro-runtime-jitsurei`, project-relative path `services/hospital-capacity/src/HospitalCapacity/Store.hs`
(artifact-level URI pending):

```haskell
runDurableCommand
  :: (BoolAlg phi (RegFile rs, ci), Eq co)
  => ServiceTracer
  -> HospitalCapacityStore
  -> CommandId
  -> ValidatedEventStream phi rs s ci co
  -> Stream (EventStream phi rs s ci co)
  -> ci
  -> [InlineProjection co]
  -> IO (Either CommandFailure CommandSuccess)
runDurableCommand tracer store commandId eventStream targetStream command projections = do
  result <-
    runHospitalCapacityStore store $
      runCommandWithProjections (commandOptionsWithId tracer commandId) eventStream targetStream command projections
  pure $
    case result of
      Left storeError -> Left (CommandStoreFailed storeError)
      Right (Left commandError) -> Left (CommandProcessorFailed commandError)
      Right (Right commandResult) -> Right (toCommandSuccess commandResult)
```

The outer store error and inner command error remain distinct in `CommandFailure`. The validated
stream was checked before execution; callers do not pass an unchecked raw definition here.

## Four registered views

From `mori://shinzui/keiro-runtime-jitsurei`, project-relative path `services/hospital-capacity/src/HospitalCapacity/Store.hs`
(artifact-level URI pending):

```haskell
registerHospitalCapacityReadModels :: Store :> es => Eff es ()
registerHospitalCapacityReadModels =
  mapM_ register
    [ readModelRegistration hospitalReadinessReadModel
    , readModelRegistration transferDecisionReadModel
    , readModelRegistration transferCandidateReadModel
    , readModelRegistration GeneratedAcceptedTransferNeeds.acceptedTransferNeedsReadModel
    ]
 where
  register (modelName, modelVersion, modelShapeHash) =
    void (registerReadModel modelName modelVersion modelShapeHash)
```

Hospital readiness, transfer decisions, transfer candidates, and accepted transfer needs are
registered explicitly. The current generated contracts declare `Eventual`; inline updates do
not change that declared consistency or turn a query view into aggregate authority.

From `mori://shinzui/keiro-runtime-jitsurei`, project-relative path `services/hospital-capacity/src/HospitalCapacity/Hospital/Projection.hs`
(artifact-level URI pending):

```haskell
hospitalReadinessReadModel :: ReadModel HospitalReadinessQuery (Maybe HospitalReadiness)
hospitalReadinessReadModel =
  ReadModel
    { name = Generated.hospitalReadinessReadModel.name
    , tableName = Generated.hospitalReadinessReadModel.tableName
    , schema = Generated.hospitalReadinessReadModel.schema
    , subscriptionName = Generated.hospitalReadinessReadModel.subscriptionName
    , version = Generated.hospitalReadinessReadModel.version
    , shapeHash = Generated.hospitalReadinessReadModel.shapeHash
    , defaultConsistency = Generated.hospitalReadinessReadModel.defaultConsistency
    , strongScope = Generated.hospitalReadinessReadModel.strongScope
    , query = \(HospitalReadinessQuery hospitalId) ->
        Tx.statement (idText hospitalId) selectHospitalReadinessStmt
    }
```

The wrapper preserves generated identity/schema/shape facts and supplies its hand-owned typed SQL
query. Hospital, Capacity, and Reservation projections update application tables under
`hospital_capacity`, and views remain rebuildable from durable input.
