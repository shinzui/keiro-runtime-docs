Hospital, Capacity, and Reservation are the durable aggregate boundaries. Surge and Supply
transducers cover orchestration/supporting domain behavior. Keiki owns runtime state transitions;
Keiro DSL owns checked service topology, generated facts, and harnesses.

## Hospital runtime state

From `mori://shinzui/keiro-runtime-jitsurei`, project-relative path `services/hospital-capacity/src/HospitalCapacity/Hospital/Transducer.hs`
(artifact-level URI pending):

```haskell
type HospitalRegs =
  '[ '("hospitalId", HospitalId)
   , '("divertStatus", DivertStatus)
   , '("surgeMode", Bool)
   , '("capacityLevel", CapacityLevel)
   , '("availableServiceLines", [ServiceLine])
   , '("activeRegionalDemand", Int)
   , '("supplyConstrained", Bool)
   ]
```

The runtime keeps service lines as a list, demand as a counter, and supply/divert state explicitly.
These are hand-owned rules; the specification does not claim to lower every list operation or
arithmetic update. Domain behavior remains authoritative in the runtime transducers and tests.

## Validated streams and generated identity

From `mori://shinzui/keiro-runtime-jitsurei`, project-relative path `services/hospital-capacity/src/HospitalCapacity/Hospital/EventStream.hs`
(artifact-level URI pending):

```haskell
type HospitalEventStreamDef =
  EventStream (HsPred HospitalRegs HospitalCommand) HospitalRegs HospitalVertex HospitalCommand HospitalEvent

type HospitalEventStream =
  ValidatedEventStream (HsPred HospitalRegs HospitalCommand) HospitalRegs HospitalVertex HospitalCommand HospitalEvent

hospitalEventStream :: HospitalEventStream
hospitalEventStream = mkEventStreamOrThrow "Hospital" hospitalEventStreamDef

hospitalStream :: HospitalId -> Stream HospitalEventStreamDef
hospitalStream hospitalId = Stream.entityStream Generated.hospitalCategory (idText hospitalId)
```

The raw definition still supplies codec and initial state, but durable runners receive its
validated wrapper. `entityStream` combines a generated checked category with the application ID.
Capacity and Reservation use the same raw/validated split with their own category and codecs.

Generated modules live alongside create-once Hole modules; their types may differ from runtime
representations. Changes must pass the DSL harness as well as application tests. The optional
Hospital symbolic suite exercises SBV/z3 proofs separately from ordinary runtime execution.
