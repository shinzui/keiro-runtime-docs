Incident, FieldResource, and Triage each keep a hand-owned Keiki transducer and codec. The
`.keiro` specification supplies a parallel checked topology and generated facts/harnesses; it
does not erase the runtime's list-valued registers or conditional domain rules.

## Runtime registers

From `mori://shinzui/keiro-runtime-jitsurei`, project-relative path `services/incident-command/src/IncidentCommand/Incident/Transducer.hs`
(artifact-level URI pending):

```haskell
type IncidentRegs =
  '[ '("incidentId", IncidentId)
   , '("commander", CommanderId)
   , '("hasCommander", Bool)
   , '("severity", Severity)
   , '("activeResourceIds", [ResourceId])
   , '("redCount", Int)
   , '("yellowCount", Int)
   , '("greenCount", Int)
   , '("safetyPerimeterEstablished", Bool)
   , '("evacuationOrdered", Bool)
   , '("evacuationComplete", Bool)
   , '("pendingTransferNeeds", Int)
   , '("closed", Bool)
   ]
```

The list-valued `activeResourceIds`, counters, and safety flags are real runtime state. The
runtime transducer enforces safety-perimeter checks before dispatch and commander/severity checks
before evacuation. Generated Domain/Holes types are a separate authoring/proof layer; do not
silently substitute their narrower representation for this runtime state.

## Raw definition and validated boundary

From `mori://shinzui/keiro-runtime-jitsurei`, project-relative path `services/incident-command/src/IncidentCommand/Incident/EventStream.hs`
(artifact-level URI pending):

```haskell
type IncidentEventStreamDef =
  EventStream (HsPred IncidentRegs IncidentCommand) IncidentRegs IncidentVertex IncidentCommand IncidentEvent

type IncidentEventStream =
  ValidatedEventStream (HsPred IncidentRegs IncidentCommand) IncidentRegs IncidentVertex IncidentCommand IncidentEvent

incidentEventStreamDef :: IncidentEventStreamDef
incidentEventStreamDef =
  EventStream
    { transducer = incidentTransducer
    , initialState = IncidentNotDeclared
    , initialRegisters = initialIncidentRegs
    , eventCodec = incidentCodec
    , resolveStreamName = Stream.streamName
    , snapshotPolicy = Never
    , stateCodec = Nothing
    }

incidentEventStream :: IncidentEventStream
incidentEventStream = mkEventStreamOrThrow "Incident" incidentEventStreamDef

incidentStream :: IncidentId -> Stream IncidentEventStreamDef
incidentStream incidentId = Stream.entityStream Generated.incidentCategory (idText incidentId)

incidentCommandStream :: IncidentId -> Stream IncidentCommand
incidentCommandStream incidentId = Stream.entityStream Generated.incidentCategory (idText incidentId)
```

`incidentEventStreamDef` owns the raw transducer/codec/snapshot configuration. Construction with
`mkEventStreamOrThrow` validates it once; command runners accept the validated value. Typed entity
streams use the generated checked category rather than concatenating arbitrary stream names.
The hand codec still owns event tags, schema version, encode/decode, and upcasters.

FieldResource and Triage follow this same pattern in their respective `EventStream` modules.
