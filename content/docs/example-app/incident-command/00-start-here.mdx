This ordered source tour reads Incident Command at `e3c800e` in
`mori://shinzui/keiro-runtime-jitsurei`. The service owns Incident, FieldResource, and Triage aggregates, escalation, and evacuation, with an independent database,
migration plan, CLI, and worker. Public messages cross through Kafka; PGMQ remains Hospital-local.

The permanent `.keiro` spec and generated facts/harnesses coexist with hand-owned Keiki runtime
transducers, codecs, queries, and effects. Read the
[ownership guide](/docs/example-app/overview/00-what-it-demonstrates) before changing generated files.
Durable commands accept validated event streams and a process-level store runner. Read models
are registered explicitly; declared Eventual consistency is not upgraded by inline delivery.

The app pins Keiro 0.3/Keiki 0.2 and its companion July runtime baseline. The current library
references elsewhere on this site cover newer releases; retain the app's checked dependency pins
when reproducing this tour.
