title: "05 — Escalation process manager and timers"
description: "The escalation process manager that reacts to a critical incident, schedules a durable timer, and fires mutual-aid when the timer elapses."
---

Escalation is stateful orchestration: it records that a critical incident needs acknowledgement,
remembers timer identity, and reacts after a severity-dependent deadline. The permanent spec records
process topology; the severity calculation remains in hand-owned code.

## The process manager

From `mori://shinzui/keiro-runtime-jitsurei`, project-relative path `services/incident-command/src/IncidentCommand/Escalation.hs`
(artifact-level URI pending):

```haskell
incidentEscalationProcessManager :: IncidentEscalationProcessManager
incidentEscalationProcessManager =
  ProcessManager
    { name = incidentEscalationProcessName
    , correlate = \input -> idText input.incidentId
    , eventStream = escalationEventStream
    , streamFor = escalationStream . mustIncidentIdText
    , targetEventStream = incidentEventStream
    , targetProjections = const [incidentDashboardProjection]
    , handle = \input ->
        let timer = escalationTimerRequest input.incidentId (escalationDeadline input.raisedAt input.severity)
         in ProcessManagerAction
              { command =
                  NoteCriticalIncident
                    NoteCriticalIncidentData
                      { incidentId = input.incidentId
                      , severity = input.severity
                      , timerId = timerIdText timer.timerId
                      }
              , commands = []
              , timers = [timer]
              }
    }

escalationStream :: IncidentId -> Stream EscalationEventStreamDef
escalationStream incidentId = Stream.entityStream GeneratedProcess.incidentEscalationCategory (idText incidentId)
```

The manager correlates by incident ID and writes its own validated stream. The generated category
feeds `entityStream`; do not concatenate a compound category string manually. The action records
`NoteCriticalIncident` and schedules the timer together. Its target stream is the Incident aggregate.

## Deadline and timer delivery

From `mori://shinzui/keiro-runtime-jitsurei`, project-relative path `services/incident-command/src/IncidentCommand/Escalation.hs`
(artifact-level URI pending):

```haskell
escalationWindow :: Severity -> NominalDiffTime
escalationWindow = \case
  Minor -> 60 * 60
  Major -> 15 * 60
  MassCasualty -> 5 * 60
  HazardousMaterials -> 5 * 60

runIncidentEscalationTimerWorker
  :: (HasCallStack, IOE :> es, Store :> es, Error StoreError :> es, KirokuStoreResource :> es)
  => RunCommandOptions
  -> UTCTime
  -> Eff es (Maybe TimerRow)
runIncidentEscalationTimerWorker options now =
  runTimerWorker Nothing now $ \timer ->
    let TimerRow
          { timerId = claimedTimerId
          , processManagerName = claimedProcessManagerName
          , correlationId = claimedCorrelationId
          } = timer
     in if claimedProcessManagerName == incidentEscalationProcessName
      then do
        let incidentId = mustIncidentIdText claimedCorrelationId
            timerText = timerIdText claimedTimerId
            firedEventId = EventId (namedUuid ("incident-escalation-fired:" <> claimedCorrelationId))
        result <-
          runCommand
            options{eventIds = [firedEventId]}
            escalationEventStream
            (escalationStream incidentId)
            (MarkEscalationTimerFired MarkEscalationTimerFiredData{incidentId, timerId = timerText})
        case result of
          Right{} -> pure (Just firedEventId)
          Left CommandRejected -> pure (Just firedEventId)
          Left{} -> pure Nothing
      else pure Nothing
```

The timer worker filters ownership, derives a stable fired-event ID, and runs the PM command through
the validated command API. The source treats successful and already-rejected timer commands as a
completed timer disposition; other failures return no completion ID. The enclosing worker reports
its result rather than treating a claimed row as proof of durable progress.
