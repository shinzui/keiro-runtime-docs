## 0.9.1.0 — 2026-08-20

- **keiki:** default inversion-ambiguity checks prove complementary standard `Bool` register guards disjoint using the exact two-value domain.
  Unsupported or opaque guards retain conservative warnings. Runtime replay APIs are unchanged.
- **keiki-codec-json / keiki-codec-json-test:** coordinated release with the 0.9 dependency range.
  Codec APIs and JSON wire format are unchanged.

## 0.9.0.0 — 2026-08-04

- **Breaking — keiki:** `WireCtor` and `InCtor` construction is sealed behind read-only patterns.
  Use Generic/TH-derived producers for trusted evidence or `unavailableWireCtor` / `unavailableInCtor` for manual behavior.
  Use rename helpers instead of record updates.
- **keiki:** adds structural constructor schemas and typed input-to-wire alignment for checked composition.
  Optional symbolic ambiguity analysis removes warnings only for definite disjointness proofs.
- **keiki-codec-json / keiki-codec-json-test:** internal bounds move to the 0.9 family; JSON wire format is unchanged.

## 0.8.0.0 — 2026-08-02

- **Breaking — keiki:** ordinary `lit` / `TLit` values require `Show`.
  Use `opaqueLit` for values without `Show` or for deliberate redaction, and handle `TOpaqueLit` in exhaustive matches.
- **Breaking — keiki:** Mermaid output defaults to readable guards and complete updates.
  `MermaidOptions` replaces the former summary flags with explicit rendering modes.
  Use `toTopologyMermaid` or `topologyMermaidOptions` for compact topology output.
- **keiki-codec-json / keiki-codec-json-test:** coordinated 0.8 bounds; JSON wire format is unchanged.
