## Store 0.12 cohort — 2026-10-26

- **Breaking — kiroku-store 0.12.0.0:** `SubscriptionTarget` adds `CategoryNamespace Text`, matching an exact category plus colon-delimited descendants, including future categories. Update exhaustive target/event matches and low-level notifier/FSM records.
- **kiroku-store-migrations 0.7.2.0:** migration 0016 permits `category_namespace` bindings in existing columns. Stop affected workers, apply it, then restart Store 0.12 binaries. Older binaries must not manage namespace bindings.
- Namespace workers scan bounded global windows and decode matching payloads. Checkpoints may pass the last delivered match; sparse replay still scans global history independently per member. Practical performance acceptance does not prove zero slowdown or historical replay throughput.
- Startup failures emit typed details and one crashed stop. Decode retries retain the initial filter/selector decision. Low-level initialization inherits uniform sibling topology under its lock without repairing existing rows.
- **Breaking — kiroku-metrics 0.4.0.0:** disabled CORS now refuses any Origin-bearing socket upgrade. Set the browser origin explicitly, including behind a proxy. The inspector sanitizes startup failures; a second termination signal forces exit 130.
- **kiroku-otel 0.3.0.0:** adopts the expanded event surface without duplicating terminal spans. **kiroku-cli 0.2.0.11** admits Store 0.12 while retaining 0.11 support; its API is unchanged. The adapter's separate release is recorded on its own page.
- Corrected historical notes identify omitted 0.10 record/constructor changes and 0.11 selector ambiguities. Narrow imports or disambiguate conflicting record selectors. Ordinary resize is not a lossless recovery procedure for incomplete legacy groups; dedicated recovery remains deferred.

## Structured errors — 2026-10-20

- **kiroku-store 0.11.0.1:** preserves SQLSTATE and server messages from script sessions. Missing relations return `UnexpectedServerError "42P01"`; serialization/deadlock failures return `TransientTransactionFailure`. Public pooled reads retain typed connection/acquisition errors. Update callers that only match `ConnectionError`.
- **kiroku-metrics 0.3.0.1:** maps typed transient failures to sanitized 503 responses and permanent server errors to 500, retaining existing envelopes.


## kiroku-store

### 0.11.0.0 — 2026-10-11

- **Breaking:** the closed `Store` effect adds five inspection operations; custom interpreters must handle them.
  Complete `Subscriber` records must supply `subDropped`.
- Adds stream/category browsing, canonical event lookup, paged subscription dead letters, and same-statement stream/head reads.
  `subscribePublisherWith` exposes dropped-batch counts and idempotent deregistration.

### 0.10.0.0 — 2026-10-10

- **Breaking:** use validated consumer-group, batch, and buffer constructors.
  Decode hooks return typed failures; subscription configuration gains undecodable-event handling and optional stall warnings.
- Apply migrations 0013 and 0014 with subscription workers stopped.
  Startup checks persisted group size and target binding; legacy target adoption must be explicit.
- Adds transactional group resize and target rebinding, bounded decode retries, and advisory handler-stall detection.
  Fixes reconnect progress retention and constraint-specific append error classification.

### 0.9.0.1 — 2026-09-25

- Forces the idle publisher's global position before storing it.
  This prevents unevaluated position updates from retaining earlier query results during sustained appends.

## kiroku-store-migrations

### 0.7.1.0 — 2026-10-11

- Migration 0015 adds the partial name index used by catalog and literal-prefix reads.
  Schedule a write pause for its transactional index build on large stores.

### 0.7.0.0 — 2026-10-10

- **Breaking:** migration 0014 adds subscription target-binding columns and removes the unused `stream_name` column.
  Stop subscription workers before applying it and restart with store 0.10 or later in the matching cohort.
- Migration 0013 records group size from existing members.
  Incomplete legacy groups refuse startup until explicitly resized.

### 0.6.0.0 — 2026-09-25

- **Breaking:** migration 0012 backfills and indexes category values on `$all` junction rows.
  Store 0.8 and older appenders cannot write the new shape: stop them before migration and start store 0.9 afterward.
- The backfill blocks appends until commit. Use a maintenance window for large stores and vacuum/analyze afterward.

## kiroku-metrics

### 0.3.0.0 — 2026-10-11

- **Breaking:** configuration adds CORS; client/server message sums add unsubscribe and coded-error constructors.
  Full `ServerProviders` construction supplies six fields. Qualify ambiguous record labels from new umbrella exports.
- Adds capabilities discovery, standalone `kiroku-inspect`, stream/category/event browsing, subscription checkpoints, and dead-letter inspection.
  CORS is disabled by default.
- WebSocket tails expose original stream names, structured error codes, and overflow notices.
  Unsubscribe/resubscribe controls periodic metrics without duplicate workers; server acquisition waits for readiness and propagates bind failures.

### 0.2.0.0 — 2026-10-10

- **Breaking:** lifecycle counters add publisher decode failures, undecodable stops, and handler stalls.
- JSON and Prometheus distinguish those outcomes; advisory stalls do not advance subscription positions.
  Requires store 0.10 and CLI 0.2.0.9.

### 0.1.0.10 — 2026-09-25

- Requires store 0.9.0.1 and CLI 0.2.0.8 for the publisher retention fix; wire format and API are unchanged.
