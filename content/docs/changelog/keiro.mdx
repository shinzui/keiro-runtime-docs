## 0.22.0.0 — 2026-10-27

- **New package — keiro-ops-http:** serves the shared operator command tree over HTTP, with live schema verification, bounded reads/delivery, explicit mutation confirmation, shared WebSocket first-page views, and prefix composition. Application hooks expose aggregate and process-manager inspection; the standalone server has database-only hooks.
- **Breaking — runtime cohort:** requires Store 0.12, migrations 0.7.2, Shibuya 0.12, adapter 0.18 and PGMQ 0.7. Stop affected subscriptions for Kiroku migration 0016 and apply PGMQ migration 0007 before queue traffic. The framework plan has 48 entries. Partitioned queues require polling.
- **Breaking — application APIs:** complete `RunCommandOptions` records supply `inspectionProvenance`; complete `AppHooks` supply `aggregates` and `processManagers`. Defaults leave provenance and catalogs disabled. Handle `OpsOutcome.InspectionFailed`, new inspection records and Shibuya's `deliveryStatus` field.
- **keiro-dsl:** candidate Language 6 supports exact mapped structural enum equality and qualified constructor literals. Regenerate finite-domain projections and conformance evidence; update exhaustive API matches and structural-equality record fields. `AggregateMapped` remains a bidirectional compatibility pattern.
- **Operations:** `pgmq dlq read` reserves messages for 30 seconds and requires confirmation. Bounded workflow continuations can refuse oversized cursors; default workflow browsing uses `wf-key2`. Timer/shard observations use database clocks. Reaction inspection does not claim modern reaction provenance.
- **Coordinated packages:** all eight packages release together; use default-record updates and regenerate clients before compiling the complete service. No Keiro-owned migration is added.


## 0.21.0.0 — 2026-10-14

- **Breaking — keiro-dsl:** scalar contract fields now use `CScalar ContractScalarType`; list fields use `CList`.
  Mapped construction extends public expressions, records, diagnostics, and binding obligations.
  Extend exhaustive matches and supply the new optional lift fields.
- **keiro-dsl:** candidate Language 6 adds scalar lists in integration contracts and versioned scalar write lifts for mapped registers.
  Generated names preserve word boundaries in reserved segments, such as `jobType` and `thingType`.
  Rename affected consumer references and create-once hole bindings while preserving application code.
- **keiro-dsl:** fixes read-model harness imports, history-backed witnesses for hole-owned initial transitions, contract parsing, and removal/replay reporting.
  Regenerate and compile the affected harnesses.
- **keiro-migrations / keiro-ops:** schema verification accepts binding views registered with `managed_by = 'keiro'`.
  Migration-owned differences and unregistered additions still report drift.
- **keiro / keiro-core / keiro-pgmq / keiro-test-support:** coordinated version and internal dependency updates.
  This release adds no database migration. Language 6 remains a candidate upstream.

## 0.20.0.0 — 2026-10-12

- **Breaking — package set:** adopts Kiroku store 0.11, migrations 0.7.1, and adapter 0.6.0.1.
  Subscription configuration uses validated constructors. Custom interpreters must handle five additional `Store` constructors.
  Complete `Subscriber` records must supply `subDropped`; exhaustive `ShardWorkerError` matches must handle `ShardReaderStartupFailed`.
- **keiro-migrations / keiro-test-support:** the composed plan reaches 47 migrations.
  Stop subscription workers for Kiroku migrations 0013 and 0014; plan a write pause for the 0015 index build on large stores.
- **keiro:** adds guarded catalog command preconditions and atomic shard-count resizing for stopped, unowned groups.
  Mismatched shard startup refuses before inserting lease rows; typed decode failures receive deterministic classification.
- **keiro-test-support:** adds fixtures with independent stores sharing one database and durable benchmark databases.
- **keiro / keiro-dsl / keiro-pgmq:** adopts Shibuya core 0.10.0.1.
  PGMQ packages stay within the 0.6 family and the PGMQ adapter stays on 0.16.1.

## 0.19.0.1 — 2026-10-05

- **keiro / keiro-ops / keiro-pgmq / keiro-test-support:** admits Effectful 2.7 alongside 2.6.
  Bounds exclude effectful-core 2.7.0.0 through 2.7.1.0 because of its dynamic-dispatch performance regression.
- **keiro-core / keiro-dsl / keiro-migrations:** coordinated release with the compatible package set.
  No source API, database, or fixture changes are required.
