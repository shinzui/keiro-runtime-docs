## 0.9.1.0 — 2026-09-21

- Preserves the earliest unresolved retry boundary across buffered and duplicate callbacks.
  Assignment generations fence callbacks retained across partition reassignment when `kafkaRebalanceHandler` is installed.
- Serializes finalizers and raises exhausted acknowledgement errors synchronously through `KafkaAcknowledgementException`.
  Successful duplicates are harmless; failed or cancelled attempts can retry.
- Requires Shibuya core 0.10 and excludes effectful-core 2.7.0.0 through 2.7.1.0.
  `AckDeadLetter` still warns and stores the offset; this adapter supplies no dead-letter producer.

## 0.9.0.1 — 2026-09-15

- Widens Effectful core bounds to admit 2.7 without changing source APIs.
- Requires Shibuya core 0.9.0.1 and kafka-effectful 0.3.1 for the corresponding compatible dependency set.

## 0.9.0.0 — 2026-08-10

- **Breaking dependency update:** requires Shibuya core 0.9, including application-defined dead-letter reasons.
- Dead-letter warnings use the public reason renderer so application codes and detail appear in the log.
  Offset acknowledgement behavior is unchanged.
