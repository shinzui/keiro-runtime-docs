## 1.2.0.0 — 2026-09-18

- **Breaking — pg-migrate-test-support:** requires ephemeral-pg 0.3.1 through the 0.3 family.
  Callers constructing its public `Config` must supply `sweepStaleOnStart`.
- **pg-migrate-test-support:** adds `defaultEphemeralConfig` with a stable per-user temporary root.
  Default fixture helpers use it so later runs can reclaim clusters abandoned by interrupted tests.
- **pg-migrate / pg-migrate-cli / pg-migrate-embed / both import adapters:** coordinated 1.2 bounds; no API or behavior change in these five packages.

## 1.1.0.0 — 2026-07-13

- **Breaking — pg-migrate:** reports gain `cleanupIssues`; `CleanupFailed` requires a primary error.
  Validation/error sums add cases. Durable success survives advisory cleanup failures; history import requires sufficient payload evidence.
- **Breaking — pg-migrate-cli:** explicit execution values become optional overrides; use `ExitSucceeded` and `check --manifest PATH`.
  The accidental Prelude export is removed. Absent flags preserve application runner settings.
- **Breaking — pg-migrate-embed:** error sums gain BOM and concurrent-modification diagnostics.
  SQL embedding scales to large payloads; the GHC 9.12 recompile plugin rechecks sibling-file membership.
- **Breaking — pg-migrate-import-codd:** commands gain `allowEquivalent`; the unreachable empty-selection error is removed.
  Source lock keys are range-checked and strict source selection rejects missing rows.
- **Breaking — pg-migrate-import-hasql-migration:** removes its unreachable empty-selection error; audit evidence records the qualified source table.
- **Breaking — pg-migrate-test-support:** removes the cleanup-only callback error; successful values survive connection-release failure.
  Asynchronous callback exceptions propagate after cleanup.

## 1.0.0.0 — 2026-07-10

- **pg-migrate:** initial stable plan model, versioned ledger, runner, repair, inspection, and generic history importer.
- **pg-migrate-cli:** reusable command tree, typed dispatcher, completion, and JSON reports.
- **pg-migrate-embed:** manifest v1, exact-byte embedding, validation, and conservative migration authoring.
- **pg-migrate-import-codd:** Codd V1–V5 history import with source-first locking and manifest evidence.
- **pg-migrate-import-hasql-migration:** qualified-table history import with MD5 verification and SHA-256 evidence.
- **pg-migrate-test-support:** isolated ephemeral PostgreSQL fixtures and structured startup, migration, callback, and cleanup failures.
