## 0.16.1.0 — 2026-09-21

- Moves a delivery to the dead-letter queue by claiming the source and producing the copy in one transaction.
  Retrying after an ambiguous successful commit does not produce a second copy; failed sends roll back the claim.
- Serializes concurrent finalizers with cancellation-safe ownership.
  Exhausted acknowledgement errors raise `PgmqAcknowledgementException` synchronously so Shibuya retains terminal failure.
- Requires Shibuya core 0.10, accepts pg-migrate 1.2 in test components, and excludes effectful-core 2.7.0.0 through 2.7.1.0.

## 0.16.0.0 — 2026-09-16

- **Breaking:** `FifoReadStrategy` gains `HeadPerGroup`; extend exhaustive matches.
- Grouped-head reads support polling and long polling on PGMQ 1.12 or later.
  Each batch contains at most one eligible head per group, so delayed heads block only their own group.

## 0.15.0.0 — 2026-09-14

- **Breaking dependency update:** requires the PGMQ 0.6 family, including its expanded queue-metrics record.
  The adapter's own public signatures are unchanged and it remains paired with Shibuya core 0.9.
- Schema installation reaches PGMQ 1.13 through append-only migrations while preserving queue data.
