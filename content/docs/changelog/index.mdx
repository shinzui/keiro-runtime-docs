Read the recent release history for every public package in the runtime cohort.
The initial history includes the latest three published versions per package, verified on **2026-10-14** against Hackage and upstream tags.
Package families share entries when they release together; Kiroku packages retain their independent version numbers.

Release history records shipped changes. The [compatibility matrix](/docs/getting-started/compatibility-and-upgrades) separately records the source versions reviewed by the API documentation.
A newer changelog entry does not advance that review or establish compatibility between independently released packages.
Dates in the entries follow upstream release notes.
