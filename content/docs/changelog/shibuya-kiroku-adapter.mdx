## 0.7.0.0 — 2026-10-26

- **Breaking:** requires Store 0.12 and Shibuya core 0.12. Handle `CategoryNamespace Text` in exhaustive target matches and supply `deliveryStatus` in direct core records.
- Supports namespace fan-in in single and grouped configurations. Apply Kiroku migration 0016 before namespace workers start; each member scans global windows and checkpoints can pass the last matching event.
- Adapter functions/configuration retain their shapes. Ack-coupled deliveries initialize `deliveryStatus` to `pure DeliveryCurrent`.


## 0.6.0.1 — 2026-10-11

- Requires Kiroku store 0.11 for the inspection cohort; the adapter API is unchanged.

## 0.6.0.0 — 2026-10-10

- **Breaking:** configuration uses validated batch, buffer, and consumer-group sizes.
  Construct those values through the re-exported smart constructors.
- **Breaking:** both configurations gain `retryPolicy` and `handlerStallWarnAfter`.
  The default permits five total deliveries and disables stall warnings.
- Adds `kirokuProcessor` with single-processor defaults and a one-second synchronous-exception retry guard.
  Requires Kiroku store 0.10. Pending raw acknowledgements remain pending; stall warnings remain advisory.

## 0.5.1.5 — 2026-09-25

- Requires Kiroku store 0.9.0.1 to include the idle-publisher retention fix; the adapter API and behavior are unchanged.
