A `.keiro` file is a typed service specification. It starts with one context, may choose module
placement, declares shared types/rules, and then declares top-level nodes. The current grammar has
**seventeen** top-level node constructors; nested projections, snapshots, timers, and patches are
documented with their owners below.

## File structure

```keiro-dsl
language keiro-dsl 6
context hospital-capacity
module Acme.Services
layout collocated

id TransferReservationId prefix=rsv
enum DivertStatus { Open=open TotalDivert=total-divert }
rule lifeCriticalOverride : DivertStatus -> Bool
  ex Open => true ; TotalDivert => false

# top-level nodes follow
```

Put `language keiro-dsl 6` before `context` in every complete source file.
The declaration selects the grammar and runtime contract before body parsing.
See [language selection](/docs/keiro/reference/keiro-dsl-language-versions) for validation and profile identifiers.

`#` begins a line comment. Whitespace and newlines separate tokens but indentation is not structural;
keywords and braces define the grammar. Quoted strings support `\"`, `\\`, `\n`, `\t`, and `\r`;
raw line breaks inside a quoted string are rejected.

Identifiers use ASCII letters, digits, and underscores. Node/type/constructor names are
`PascalCase` where the grammar expects generated constructors. Fields and registers begin with a
lowercase letter or `_`. Haskell keywords, duplicate names, unsafe constructor forms, and generated
vertex-constructor collisions are rejected.

## Module placement

Both placement clauses are optional:

| Clause | Values/default | Effect |
|---|---|---|
| `module <Dotted.Prefix>` | no prefix | Prepends a PascalCase namespace to generated and hole modules |
| `layout <style>` | `prefixed` | `prefixed` uses `Generated.<Ctx>…`; `collocated` uses `<Ctx>.<Node>.Generated…` |

CLI `--module-root` and `--collocate` flags override the corresponding spec clauses. Precedence is
CLI flag, then spec clause, then built-in default.

## Shared declarations

- `id Name prefix=text` generates a `Text` newtype and records its durable prefix.
- `enum Name { Constructor=wire-spelling … }` defines a closed enum and explicit wire spellings.
- `rule name : Enum -> Bool` followed by `ex Constructor => expression` rows defines a total rule for
  use in aggregate expressions.

Rules must resolve their enum domain, cover every constructor exactly, and use known constructors.
Changing an ID prefix or enum wire spelling is breaking evolution.

`projection`, `snapshot`, and `timer` are not independent top-level nodes. A patch and
`continueAsNew` are workflow body items. An operation is top-level but owns no persisted decode or
identity surface of its own; it validates references to other nodes.

The six catalog nodes — `target`, `rebuild-group`, `projection-owner`, `projection-revision`,
`external-read`, and the `group`/`targets`/`backing` clauses on `readmodel` — use the catalog capabilities
(`ProjectionCatalogSyntax` and `ExternalReadContractSyntax`).

## Ownership and generated output

`HOLE` means behavior remains hand-owned. Scaffold creates hole modules only when absent and
overwrites only files marked `-- @generated`. Typical output is:

| Node | Generated | Hand-owned |
|---|---|---|
| aggregate | `Domain`, `Codec`, `EventStream`, `Projection`, `Harness` | `Holes` |
| read model | `ReadModelTable`, `ReadModel`, `ReadModelHarness` | `ReadModelHoles` |
| process | `Process`, `ProcessHarness` | `ProcessHoles` |
| router | `Router`, `RouterHarness` | `RouterHoles` and runtime value/fill |
| contract/intake/publisher | `Contract`, `Inbox`, `Publisher` | integration/transaction fills |
| workqueue | `Queue`, `QueuePolicy` | fan-out, handler, and raw-SQL dedupe fills |
| workflow | `WorkflowFacts`, `WorkflowRuntime` | workflow body module |

Operations primarily validate and connect references; they do not produce a separate generated
module. Always use the emitted manifest as the exact module/dependency inventory for a concrete spec.

## Aggregate transition expressions

A transition's guard and register writes are a small **typed scalar
expression language**, checked at `check` time and lowered into structural Keiki terms.

```keiro-dsl
  Open -- Adjust -->
    guard cmd.balance + reg.balance >= -100
      && reg.reserved + cmd.requested <= reg.capacity
      && cmd.observedAt >= reg.openedAt
      && cmd.limits.minimum >= reg.limits.minimum
      && cmd.active == false
      && cmd.mode == reg.mode
      && cmd.requestId == reg.requestId
    write balance := reg.balance + cmd.balance * 2
    write reserved := reg.reserved + (cmd.requested - reg.capacity)
    write machine := -7
    write label := "adjusted"
    write active := true
    write mode := AccountMode.Restricted
    write requestId := RequestId("req_01h455vb4pex5vsknk084sn02q")
    write openedAt := "2026-02-03T04:05:06Z"
    write limits := cmd.limits
    emit Adjusted
    goto Reviewed
```

    "reg.<name>": { type: "root", description: "Reads a register. A bare register name is also accepted where unambiguous." },
    "cmd.<field>": { type: "root", description: "Reads a field of the consumed command." },
    "<root>.<path>": { type: "structural path", description: "Reads into a mapped structural type. The path is required and checked against the resolved wire shape." },
    "+ - *": { type: "arithmetic", description: "Exact Integer arithmetic; for Natural, + and * plus total monus subtraction." },
    "== != < <= > >=": { type: "comparison", description: "Same-declaration equality and ordering. Cross-declaration, nominal-to-Text, and unqualified enum comparisons are rejected at check time." },
    "&& ||": { type: "boolean", description: "Guard composition." },
    "<Enum>.<Ctor>": { type: "enum literal", description: "Must be qualified by its declaration." },
    "<Id>(\"…\")": { type: "nominal literal", description: "Validated against the declared identifier domain." },
  }}
/>

<Callout type="warn">
  **`Natural` subtraction is total monus, not partial subtraction.** `reg.reserved - reg.capacity`
  evaluates to `0` when `capacity` exceeds `reserved` — it does not throw and does not go negative.
  Both the concrete evaluator and the solver agree on this. If you meant "fail when it would go
  negative", write the ordering guard explicitly. See [the keiki term
  language](/docs/keiki/reference/core#the-term-language).
</Callout>

Scalar literal families cover `Integer` (including negatives), `Natural`, `Int`, `Text`, `Bool`,
`Time` (as an ISO-8601 quoted string), qualified enum constructors, and validated nominal
identifiers. Direct aggregate `Time` and `Natural` fields and registers check, scaffold, compile,
encode, snapshot, and replay — that unified policy lives in `Keiro.Dsl.AggregateType` and is shared
by validation, lowering, imports, packages, samples, fold fingerprints, diffs, replay impact, and
scaffold refusals.

### `implementation hole`

A transition may instead declare that its behaviour is **hand-owned**:

```keiro-dsl
  Reviewed -- Close -->
    implementation hole
    emit ClosedEvent
    goto Closed
```

Every transition is **exclusively** generated-owned or explicitly `implementation hole` —
never both, and never implicitly one of them. Ownership is part of the checked semantic graph, the
canonical rendering, the diff surface, the scaffold ledger, and the fold fingerprint. See
[scaffold and fill holes](/docs/keiro/how-to/scaffold-and-fill-holes) for what each owner may write.

<Callout type="info">
  The checker rejects a state-changing transition without emitted events as `AggregateEventlessStateChange`.
  An accepted edge without events must preserve its vertex and registers.
  Otherwise replay cannot reconstruct the command's state change.
  `EventOutputCommandMismatch` is the sibling code for an emitted event whose fields do not
  correspond to the consumed command.
</Callout>

## Checked values and ID domains

Language 6 accepts `mapped structural value`, `Day`, `Set Text`,
`mapped refined` with `wire base16-bytes`, and `id … prefix=… domain=typeid-v5-or-v7`.
Text-keyed maps remain `Map <value-type>`; compound arguments require parentheses.
See [mapped type syntax and limits](/docs/keiro/reference/keiro-dsl-mapped-types#language-6-checked-value-mappings)
and [explicit ID admission](/docs/keiro/reference/codec#explicit-id-admission).
