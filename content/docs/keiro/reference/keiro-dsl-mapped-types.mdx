A **mapped consumer type** lets a `.keiro` spec use a type your application already owns — an
`EmailAddress`, a `Money`, a `ShippingAddress` — in a command, event, or register, without keiro
inventing a duplicate. Two modes, and the choice between them is the whole design:

| Mode | Keiro knows | Wire authority |
|---|---|---|
| `mapped structural` | the type's full **wire shape**, field by field | the **checked declaration** and the generated codec |
| `mapped opaque` | only that a value crosses a **declared JSON boundary** | your `codec` at that boundary |

<Callout type="info">
  Prefer `structural`. It is what makes evolution diagnosable — keiro can tell you that a field was
  removed, a tag renamed, or a nullability flipped, because it knows the shape. An `opaque` value is a
  sealed box: safe, but keiro can only report *that* the boundary exists.

  The `--coverage-report` and `--fail-on-opaque` flags on
  [`check`](/docs/keiro/reference/keiro-dsl-cli#--coverage-report-file-and-the-opacity-gates) exist to
  make that trade-off visible and, when you are ready, to ratchet it.
</Callout>

<Callout type="warn">
  **A structural binding must be total.** If converting a valid shape into your consumer type can
  *fail*, the declaration is not structural and must use `opaque` instead. Consumer invariants have to
  be represented **by the shape**, not enforced by a partial constructor — see [the binding
  contract](#the-binding-contract) below.
</Callout>

## `mapped structural`

Three kinds, distinguished by their wire encoding: `record`, `enum`, and `union`.

```text
mapped structural record ShippingAddress {
  haskell package = acme-domain module = Acme.Domain.Address type = Address
  binding = "acmeAddressBinding"
  binding-version = "1"
  canonical-type = "Acme.Domain.Address/v1"
  fixtures = "acmeAddressFixtures"
  initial = "emptyAddress"
  wire object constructor = Address unknown-fields = reject {
    line1      as "line1"   : Text            required
    line2      as "line2"   : Optional Text   optional on-missing = null
    postcode   as "postcode": Text            required
    tags       as "tags"    : List Text       optional on-missing = []
  }
}
```

<TypeTable
  type={{
    haskell: { type: "package = … module = … type = …", description: "Where the consumer type lives. Unquoted: a package name, a module prefix, and a type identifier." },
    binding: { type: "quoted symbol", description: "The consumer-owned StructuralBinding value you must write." },
    "binding-version": { type: "quoted string", description: "Identity of the binding; a change is a mapped evolution finding." },
    "canonical-type": { type: "quoted string", description: "The persisted canonical identity of the mapped type, independent of its Haskell module path." },
    fixtures: { type: "quoted symbol", description: "The consumer-owned FixtureCases value the generated harness exercises." },
    initial: { type: "quoted symbol", description: "The register-initial value, when this type is used as a register." },
    wire: { type: "required", description: "The shape. The only mandatory clause — every other clause is optional at the grammar level so diagnostics can name the omission rather than fail to parse." },
  }}
/>

Each clause may appear **at most once**; a duplicate is a parse error naming the clause.

### `wire object` — records

```text
wire object constructor = <Ctor> unknown-fields = reject|ignore { <field>… }
<haskellName> as "<wireKey>" : <type> required|optional [on-missing = <default>]
```

### `wire string` — enums

```text
wire string { <Ctor> as "<wireTag>" … }
```

### `wire tagged-object` — unions

```text
wire tagged-object tag = "<tagKey>" contents = "<contentsKey>" unknown-fields = reject|ignore {
  <Ctor> as "<wireTag>" [: <type>]
}
```

An arm's payload type is optional — omit it for a nullary constructor.

### Type expressions

```text
Text  Int  Bool  Natural  Time  UTCTime  Json
Optional <t>   List <t>   Map <t>   Map[<id>] <t>
<Name>                      -- a reference to another mapped declaration
```

`Time` and `UTCTime` are synonyms. `Optional`, `List`, and `Map` take one argument, parenthesised when
it is itself a compound. A bare identifier is a **reference** to another mapped declaration, which is
what makes the graph a graph.

### Candidate Language 6 nominal leaves and keyed maps

Under `language keiro-dsl 6`, a generated or consumer-bound `id`, a nominal `enum`, or a
`mapped nominal` scalar may appear anywhere a structural leaf is supported: records, unions,
`Optional`/`List`, workqueue fields, and read-model query input/result types. The generated Haskell
shape retains the nominal type and the codec enforces the owning ID/enum/scalar contract.

`Map[TemplateId] Value` declares an identifier-keyed JSON object rather than erasing the key to
unrestricted `Text`. Keys must name a declared ID and decode under that ID's TypeID contract.
Changing the key declaration is a typed structural/evolution change.

Required structural paths may project through these leaves for same-declaration equality in guards
and declarative router selection. Cross-ID, cross-enum, and nominal-to-`Text` comparisons remain
invalid. A direct `Optional DeclaredId` aggregate field is still unsupported; place it inside a
one-field mapped structural record when optionality is required.

### `on-missing` defaults

```text
null   []   {}   true   false   "<text>"   <integer>   <Ctor>
```

## The resolved type graph

Parser declarations keep mandatory facts *optional* so diagnostics can name what is missing.
Resolution is the phase boundary after which missing facts and unresolved references are
**unrepresentable** — and it is what drives stable validation diagnostics, root-aware compatibility
vectors, replay impact, and deterministic golden stand-ins.

Resolution rejects:

| Code | Rejects |
|---|---|
| `MappedUnresolvedName` | a reference to a declaration that does not exist |
| `MappedAmbiguousName` | a name that resolves more than one way |
| `MappedRecursiveType` | a cycle in the declaration graph |
| `MappedDuplicateFieldName` / `MappedDuplicateWireKey` | two fields sharing a Haskell name or a wire key |
| `MappedDuplicateArmName` / `MappedDuplicateWireTag` | two union arms sharing a constructor or a tag |
| `MappedNonInjectiveNullability` | a nullability arrangement that cannot round-trip |
| `MappedUnsupportedEncoding` | an encoding the generator cannot emit |
| `MappedMissingIngredient` | a clause the mode requires |
| `MappedMissingInitialValue` | a register use with no `initial` |
| `MappedInvalidHaskellName` / `MappedInvalidIdentity` | an ill-formed package/module/type or identity string |
| `MappedImportConflict` | two declarations whose imports collide |
| `MappedDefaultIllTyped` | an `on-missing` default that does not match its field type |

<Callout type="info">
  Guards are where this page meets keiki. A guard can read one **scalar** out of a
  mapped consumer value through keiki's [typed field
  projections](/docs/keiki/reference/core#field-projections) — the generated
  `Generated.<Context>.Structural.StructuralProjections` facade exposes exactly the eligible total
  scalar getters.

  The `MappedGuardUnsupported` code that used to be listed here was **removed**: it was declared but
  never emitted. A guard the projection contract cannot support is reported by the structural
  coverage and projection diagnostics instead.
</Callout>

## `mapped opaque`

```text
mapped opaque AuditBlob {
  haskell package = acme-domain module = Acme.Domain.Audit type = AuditBlob
  codec = "acmeAuditCodec"
  version = "2"
  fixtures = "acmeAuditFixtures"
  initial = "emptyAudit"
}
```

Keiro delegates the value **only at its declared JSON boundary** and knows nothing of its interior. A
change to `codec` or `version` is `MappedOpaqueCodecChanged`.

## The binding contract

`Keiro.Codec.Structural` lives in `keiro-core` and is re-exported from `keiro`, so a generated consumer
keeps a single direct `keiro` dependency.

```haskell
data StructuralBinding a shape = StructuralBinding
    { bindingToShape   :: !(a -> shape)
    , bindingFromShape :: !(shape -> a)
    }

newtype FixtureCases a = FixtureCases
    { fixtureCases :: NonEmpty (Text, a) }

bindingDomainRoundTrip :: (Eq a)     => StructuralBinding a shape -> a     -> Bool
bindingShapeRoundTrip  :: (Eq shape) => StructuralBinding a shape -> shape -> Bool

encodeViaBinding :: StructuralBinding a shape -> (shape -> Value) -> a -> Value
decodeViaBinding ::
    StructuralBinding a shape -> (Value -> Either Text shape) -> Value -> Either Text a
```

Both functions in a `StructuralBinding` are **total** — that is the whole requirement, and the reason a
partial conversion must use `opaque` mode.

The two law helpers are what the generated harness exercises:
`bindingDomainRoundTrip` checks a consumer value survives conversion through its shape;
`bindingShapeRoundTrip` checks every declared shape survives conversion through the consumer type.

`FixtureCases` values are **deterministic and labelled** — never invented through `Arbitrary` or
`Default`, because a generated harness failure must keep a stable identity. The generator checks the
cases against every declared union and nullable branch, and rejects empty or duplicate labels.

<Callout type="warn">
  **Delegation is one-way.** A consumer `ToJSON`/`FromJSON` instance may delegate *to* the generated
  codec via `encodeViaBinding` / `decodeViaBinding` — that is the sanctioned direction, keeping the
  generated shape encoder as the wire authority. Keiro **never** delegates structural encoding to a
  consumer instance. All decode failure comes from parsing JSON into the generated shape; applying the
  binding introduces no hidden semantic rejection.
</Callout>

### `genericStructuralBinding`

```haskell
genericStructuralBinding ::
    (GNominalBinding (Rep a) (Rep shape), Generic a, Generic shape) =>
    StructuralBinding a shape
```

An **opt-in, exact nominal** adapter from `Keiro.Codec.Structural.Generic`. It accepts only identical
constructor names, selector names, field order, arity, and field types. There are deliberately **no**
coercion, prefix-stripping, or positional-only options: an exact representation mismatch fails at
compile time with a type error directing you to the scaffolded binding module.

It supplies nominal construction and destruction *only*. Wire keys, union tags, presence, nullability,
and defaults stay exclusively in the `.keiro` spec and the generated codec — and **both binding laws
plus the finite codec cases remain required evidence** regardless, because a generic derivation
rules out representation mistakes, not semantic ones.

## Evolution diagnostics

`diff` classifies mapped-declaration change with its own code family, each carrying a
[compatibility vector](/docs/keiro/reference/keiro-dsl-cli#compatibility-vectors) and complete
command/event/register use-site paths:

| Area | Codes |
|---|---|
| Fields | `MappedFieldAddedWithDefault`, `MappedFieldAddedNoDefault`, `MappedFieldRemoved`, `MappedFieldTypeChanged`, `MappedWireKeyChanged` |
| Presence and defaults | `MappedPresenceChanged`, `MappedNullabilityChanged`, `MappedDefaultRemoved`, `MappedDefaultChanged` |
| Unions and enums | `MappedUnionEncodingChanged`, `MappedArmAdded`, `MappedArmRemoved`, `MappedArmTagChanged`, `MappedEnumValueAdded`, `MappedEnumValueRemoved`, `MappedEnumSpellingChanged` |
| Identity and source | `MappedHaskellSourceChanged`, `MappedRecordConstructorChanged`, `MappedBindingChanged`, `MappedFixturesChanged`, `MappedInitialChanged`, `MappedCanonicalTypeChanged`, `MappedOpaqueCodecChanged` |
| Declaration lifecycle | `MappedDeclAdded`, `MappedDeclRemoved`, `MappedModeCrossed` |
| Coverage | `CoverageOpaqueSurface`, `CoverageOpaqueBoundaryAdded`, `CoverageOpaqueGateExceeded` |
| Migration evidence | `CodecCompareDifference`, `CodecCompareCoverageGap`, `CodecCompareInvalidInput` |

`MappedModeCrossed` — switching a declaration between `structural` and `opaque` — is called out
separately because it changes what keiro can *see*, not merely what it encodes.

Mapped register wire, binding, and initial identities participate in the aggregate **fold
fingerprint**, so changing one raises `AggFoldSurfaceChanged` and invalidates snapshots. See
[Snapshots](/docs/keiro/reference/snapshot).

## Scaffolding and generated modules

A spec with mapped types scaffolds:

- private `Generated.<Context>.Structural.Shape.*` wire representations, with `Generic` derived for the
  private shape types;
- structural codecs generated from the declared keys, defaults, and tags;
- opaque delegation **only** at each declared JSON boundary;
- imports of the consumer types into the aggregate domains;
- a narrow `StructuralProjections` witness facade exposing the eligible total scalar getters;
- **create-once** hand-owned binding, fixture, and register-initial skeletons, grouped by their
  declared owner modules.

Preflight refuses a consumer module placed **inside** the generated namespace before writing anything,
reports consumer packages and modules, includes consumer requirements in the manifest, persists
canonical structural/opaque mapping identities as forward-compatible JSON rows, and reports mapping
drift on later runs.

Ask what you still owe with
[`check --explain-bindings`](/docs/keiro/reference/keiro-dsl-cli#--explain-bindings); re-scaffolding
never overwrites a hole and reports granular newly-required holes instead.

<Callout type="warn">
  **Breaking rename in Keiro 0.9.0.0 — structural projection witnesses.** The witnesses in the
  `StructuralProjections` facade were named with hex-mangled identifiers; they now carry
  **deterministic owner-and-JSON-pointer** names. Witness **values and semantics are unchanged** —
  this is purely a naming change — but a hand-owned module importing a witness by its old mangled
  name will not compile. Re-scaffold, then repoint the imports.
</Callout>

## Mapped consumer surfaces

*New in Keiro 0.12.0.0, language 5 (`MappedConsumerSurfaceSyntax`).* Before this, a mapped
declaration's blast radius was inferred by hand. `Keiro.Dsl.SemanticImpact` now derives it from the
**resolved type graph**, so both the roots and the transitive declaration edges are checked facts
rather than a reconstruction from raw source.

### Who consumes a mapped declaration

```haskell
data MappedConsumer
    = AggregateConsumer Name
    | WorkqueueConsumer Name
    | ReadModelQueryConsumer Name MappedQueryPosition
    | DerivedProjectionConsumer DerivedMappedConsumer

data MappedQueryPosition = MappedQueryInput | MappedQueryResult
```

Each consumer is reached through one of seven **root kinds**:

| Root kind | Surface |
|---|---|
| `MappedCommandFieldRoot` | a command field |
| `MappedEventFieldRoot` | an event field |
| `MappedRegisterRoot` | an aggregate register — the one snapshots cache |
| `MappedWorkqueueFieldRoot` | a persisted workqueue payload field |
| `MappedReadModelQueryInputRoot` | a `query input` position |
| `MappedReadModelQueryResultRoot` | a `query result` position |
| `MappedProjectionEventRoot` | an aggregate-derived projection |

### Consequences do not collapse into one severity

```haskell
data MappedConsequence
    = MappedConsumerBuild MappedConsumer
    | MappedPrivateEventHistory Name
    | MappedSnapshotHydration Name
    | MappedWorkqueueHistory Name
    | MappedQueryApi Name MappedQueryPosition
    | MappedProjectionHandlerReview DerivedMappedConsumer
    | MappedProjectionRebuild DerivedMappedConsumer Name
```

This is the point of the feature. Changing a mapped declaration can mean *recompile your code*, or
*upcast persisted event history*, or *drain a queue*, or *rebuild a projection* — and those have
completely different adoption costs. Collapsing them into one "breaking" verdict is what made the old
reports unusable.

<Callout type="info">
  Adoption guidance separates them accordingly: event upcasting, queue drains or transitional codecs,
  query-caller recompilation, projection review/rebuild, snapshot hydration, and application-owned SQL
  migration are each a distinct decision.
</Callout>

<Callout type="warn">
  **Public contracts and heterogeneous `category`/`all` projection sources remain explicit unsupported
  boundaries**, reported as `UnsupportedProjectionSource` rather than silently inferred as consumers.
  A derived consumer is only claimed where the graph can prove it.
</Callout>

### Semantic locality

Regeneration is now **semantically local**. An aggregate harness follows only checked command,
private-event, register, workqueue, read-model-query, and aggregate-derived-projection reachability.
Declaration-wide laws move to one context-owned `StructuralConformance` module, so an unrelated
declaration elsewhere in the workspace no longer perturbs a harness.

### `BehaviorSourceMap`

One generated context module resolves frozen behavior keys to an **exact current file, line, and
column**. Aggregate behavior contracts and fresh create-once witness comments no longer embed
volatile line numbers; source movement changes the map while failures and
[`behavior-obligations`](/docs/keiro/reference/keiro-dsl-cli#behavior-obligations) still report the
current exact position.

Three diagnostics guard it: `BehaviorSourceAnchorMissing`, `BehaviorSourceAnchorInexact`, and
`BehaviorSourceAnchorCollision`. `WorkspaceSourceIndexInvalid` reports a workspace whose composed
source index cannot be trusted.

<Callout type="warn">
  **Breaking in Keiro 0.12.0.0 — regenerate once.** Each mapped service must be regenerated, its
  generated Cabal fragment reconciled with the new context `StructuralConformance` and
  `BehaviorSourceMap` modules, the runtime package recompiled, and its generated service conformance
  target run. Scaffold ledgers gain an additive `semantic-impact` baseline.

  This changes **generated layout and evidence only**. Wire, fold, snapshot, and behavior-key
  identities are unchanged.
</Callout>

`MappedReadModelLoweringPending` reports a mapped read-model query position whose lowering is not yet
available, and `ReadModelQueryInputChanged` / `ReadModelQueryResultChanged` are the `diff` codes for
the two query positions.
