---
title: "Inspection shares owner APIs"
description: "Ownership, freshness and resource costs of inspection."
---

The HTTP transport delegates to the same owner command tree as the CLI. It does not duplicate mutations in SQL. Aggregate and process-manager state require application-owned inspectors, while database-only commands can run without application code.

An inspection endpoint is an additional workload. Give it reserved connection capacity, bound computation and delivery, and verify schema on every admitted operation. A page limit bounds returned rows; it does not bound filtered scan work or payload size. Schema verification remains fresh even when an unchanged header can reuse its encoded presentation.

Feeds publish bounded first-page views. A key removed from a view may have moved beyond the page boundary. An update stream is therefore unsuitable as a durable event log. Re-read after gaps and treat database observations as the source of truth.

See the [HTTP reference](/docs/keiro/reference/ops-http) and [confirmation procedure](/docs/keiro/how-to/confirm-http-operations).
