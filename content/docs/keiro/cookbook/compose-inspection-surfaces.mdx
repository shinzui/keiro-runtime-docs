---
title: "Compose runtime inspection surfaces"
description: "Mount allocated owner applications with shared host policy."
---

Allocate each owner's WAI application once, then compose it with `composeSurfaces` from `Keiro.Ops.Http`. Stable prefixes are `/keiro`, `/kiroku`, `/shibuya` and `/pgmq`. Keep each owner's scoped resources alive for the full mount lifetime.

Keiro feeds and HTTP share `handleBudget`; pass the same complete origin list to both the Keiro child and `ComposeConfig`. Outer CORS headers do not authorize child mutations. Kiroku metrics 0.4 requires explicit browser origins even behind a same-origin proxy. Shibuya owns its socket shutdown. PGMQ uses `withInspectApplication` over a dedicated pool.

The root returns mounted surfaces; absent owners return `surface_not_mounted`, never forwarding a request. Keiro composition preserves both WAI path representations and trailing slashes. For PGMQ descriptor-relative URLs, canonicalize the mount root to `/pgmq/` and retain OpenAPI's relative server URL `.`.

Release the listener before feed handles and stores. Each child retains its own admission and deadlines; composition does not combine the owners' database consistency domains. Verify root discovery, a read through each mounted prefix, socket upgrade and shutdown. The upstream composition example mounts Keiro and Kiroku only; Shibuya/PGMQ integration remains host-owned.

Read the [HTTP reference](/docs/keiro/reference/ops-http) and [PGMQ embedding contract](/docs/pgmq/reference/inspection-server).
